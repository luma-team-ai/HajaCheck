# 하자 상세 이미지 단위 카드 및 복수 박스 선택

> **문서 버전:** v0.1 · **최종 수정:** 2026-08-03

- GitHub: #1422
- Jira: HAJA-636
- 사이클: Normal / 프론트엔드 전용

## 구현 범위

- 관리 대상 하자(`CONFIRMED`, `IN_PROGRESS`, `RESOLVED`)를 `mediaId` 기준 이미지 카드로 그룹화한다.
- `mediaId`가 없는 하자는 하자별 사진 없음 카드로 유지한다.
- 이미지 기준 필터·정렬·상태 탭 카운트와 복수 하자 요약을 제공한다.
- 상세 모달 원본 사진에 같은 이미지의 모든 유효 bbox를 둥근 선택 버튼으로 표시한다.
- 박스 또는 위치 미지정 칩 선택 시 헤더, 지표, AI 설명, 조치 폼, 활동 기록을 해당 하자로 전환한다.
- 기존 `defectId` 딥링크, 조치 전/조치/조치 완료 사진 탭, 포커스 트랩을 보존한다.

## 결정 사항

- 대표 하자: E→D→C→B→A→미분류, 동률이면 신뢰도→최신 생성일→ID 순.
- 필터: 한 하자가 활성 유형·등급·상태 조건을 모두 만족하면 이미지 카드를 표시한다.
- 정렬: 생성일은 그룹 내 최신 생성일, 신뢰도는 그룹 내 최고 신뢰도를 사용한다.
- 카드: 하자 수, 유형 최대 2종+나머지 수, 최고 등급, 상태별 건수, 최고 신뢰도, 최대 균열폭을 표시한다.
- 조치 사진 탭에는 bbox를 표시하지 않으며, 하자 선택 변경 시 조치 전 탭으로 초기화한다.
