# 하자 실측 사진 촬영 규약 — 균열 길이·폭 mm 측정 보정용 (70~80장)

> **문서 버전:** v0.1 · **최종 수정:** 2026-07-31

| 항목 | 내용 |
|---|---|
| 배경 | AI 분석이 잰 균열 폭·길이/박리·철근 면적을 **실제 mm 단위**와 연결하기 위한 보정·검증 데이터 수집. 업계 기준(허용균열폭 0.3mm)과 A~E 등급을 잇는 유일한 경로 |
| 작성 | 오영석 |
| 상태 | 제안 — 촬영 시작 전 팀 합의 필요 |
| 전제 | 2026-07-27~28 균열 등급 전면 조사 결론 위에서 작성. **모델 재학습용 아님**(보정·검증 전용이라 70~80장으로 충분 — 임계값 4개·비례상수 1개 피팅) |

---

## 1. 왜 필요한가 (요약)

- 코드만으로는 **픽셀 단위** 길이·폭 측정까지 가능. **mm 환산은 사진 속에 크기를 아는 기준물이 있어야만 가능**(현행 640 입력에서 1px≈1.5mm, 0.3mm=0.2px 서브픽셀).
- AI Hub 공식 촬영 지침도 "균열자(크랙게이지)를 대고 촬영"이지만, 실제 배포 데이터에는 균열자 사진이 없음 → **팀 자체 촬영이 유일한 소스**.
- 0.3mm급 미세 폭은 마스크 폭으로 못 재고, 어두움총량(BLACKHAT) 지표의 비례상수를 실측 폭으로 보정해야 판정 가능(합성 검증 완료, 실측 데이터만 부재).

## 2. 용처별 요구 수준 (전부 균열자가 필요한 게 아님)

| 요구 수준 | 장수 | 준비물 | 가능해지는 것 |
|---|---|---|---|
| 유형 + 육안등급 라벨만 | 70~80장 전체 | 기록 시트만 | 등급 임계값 실사진 재보정 · 균열↔박리 혼동 평가 |
| + 기준물을 같은 벽면에 붙이고 촬영 | 그중 30장 이상 | A4 용지 + 종이테이프 | mm/px 환산 검증 |
| + 균열 폭 실측값 기록 | 균열 20~30장 | 균열자(크랙게이지) | 0.3mm 서브픽셀 폭 보정(핵심) |

## 3. 촬영 규약

1. **기준물을 종이테이프로 하자 옆 같은 벽면에 붙인다** → 손으로 들 필요 없어 **혼자 촬영 가능**. 테이프는 **카드 앞면 테두리 위에 겹쳐** 붙일 것 — 뒷면에 뭉쳐 붙이면 카드가 벽에서 들떠 축척이 어긋남(2026-08-02 수집분 실제 사례).
   - 1순위: **A4 용지**(210×297mm) — 크고 구하기 쉽고 멀리서도 잘 보임.
   - 대안: 개인정보 없는 표준규격 카드(포인트·교통·멤버십, 85.6×54mm). **신용카드 금지**(번호·이름이 데이터셋에 남음).
   - 하자에서 **5~10cm 옆**, 하자를 가리지 않게. 통상 거리(약 1m)에서 그대로 찍으면 됨 — mm 환산은 원본 해상도에서 하므로 가까이 갈 필요 없음.
2. **벽 정면(수직)에서 촬영** — 비스듬하면 크기가 왜곡됨. 기준물과 하자가 **같은 평면**에 있어야 함.
   - **셀프 체크: 찍은 사진에서 기준물 테두리가 반듯한 직사각형으로 보이면 합격**, 사다리꼴로 보이면 다시(±10° 이내 목표).
3. **원본 그대로 제출** — 카카오톡 전송 금지(압축). 구글드라이브/USB로 수합.
4. **장당 기록**(공유 시트): ① 하자 유형(균열/박리박락/철근노출) ② 육안 등급(A~E) ③ 균열자 실측 폭 mm(해당분만) ④ 촬영 기기·실내외.
5. **구성 배분**: §3.2 쿼터표 준수 + **"균열인지 박리인지 헷갈리는 사진" 10장 이상 의도적으로 포함**(AI 혼동 테스트 전용).

### 3.1 통제 변수 (사진 도착 후엔 못 고침 — 촬영 시점에 반드시)

| 변수 | 규칙 | 이유 |
|---|---|---|
| **독립성** | **한 하자(벽면) = 1장.** 같은 균열을 여러 장 찍으면 전체가 1건 가치로 떨어짐. 같은 벽 연속 촬영 금지 | 이전 조사에서 470장이 실제론 84 독립건이라 통계력이 1/5로 준 사례 — 이번 데이터의 최대 리스크 |
| **조도** | **플래시 OFF 통일**, 낮 자연광 권장, 역광·강한 그림자 회피. 실내/실외를 시트에 기록 | 어두움총량(BLACKHAT) 지표가 명암 신호라 조명이 섞이면 보정값이 노이즈에 묻힘 |
| **기기** | 촬영 폰 모델을 시트에 기록, **가급적 2~3대 이내로 통일** | 카메라별 후처리(선명화·HDR)가 어두움 값에 영향 |
| **직각** | ±10° 이내(§3.2 셀프 체크) | 기울면 mm/px가 위치마다 달라져 환산 오차 |

### 3.2 유형×등급 쿼터표 (총 70~80장)

| 유형 | 목표 장수 | 등급 분포 | 비고 |
|---|---|---|---|
| 균열 | **35~40장** | 등급당 최소 5장, 특히 **심각(D·E급) 최소 10장** | 임계값 재보정+폭 회귀 둘 다 필요한 주 대상. 심각알람 경계(C/D)가 최우선 |
| 박리박락 | 15~20장 | 경미~심각 골고루, 등급당 최소 4장 | 박리 등급 성능은 현재 미측정 상태라 첫 검증 데이터가 됨 |
| ~~철근노출~~ | **수집 제외** (2026-08-02 확정) | — | 박리와 겹치는 유형이라 균열 재학습 계획에 불포함 — 별도 수집하지 않음 |
| 균열자 실측 동반(균열 중) | 20~30장 | **폭 구간 골고루: 0.3mm 미만 / 0.3~1mm / 1mm 이상** | 회귀는 장수보다 폭 범위 분산이 중요 — 같은 폭만 30개면 상수를 못 정함 |

경미 하자만 찍기 쉬운 게 자연스러운 함정 — **심각 쪽 표본이 0이면 해당 경계 재보정 자체가 불가능**해지므로 쿼터를 지켜야 함.

## 5. 준비물 체크리스트

- [ ] 균열자(크랙게이지) 1개 — 시중 수천 원, 인쇄형 카드도 무방. 균열 실측 담당 1명만 필요
- [ ] A4 용지 + 종이테이프 — 촬영자 각자
- [ ] 공유 시트(§4 양식) 1장 개설
- [ ] 규약 본 문서 팀 공유 → 합의 후 촬영 시작

## 6. 수집 후 활용 계획 (참고)

① 기준물로 mm/px 산출 → AI 측정 `width_px` 환산값 vs 균열자 실측 대조 → ② 어두움총량↔실측폭 회귀로 0.3mm 판정 비례상수 확정 → ③ 육안 등급 라벨로 A~E 임계값 실사진 재보정(스크립트 기보유) → ④ 혼동 케이스로 균열↔박리 오탐 필터 성능 실측.
